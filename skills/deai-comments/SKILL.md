# 去 AI 味注释

用户指定文件或代码片段后，识别并删除以下六种模式，其余注释一律保留不动。

## 六种 AI 味模式

**A 装饰性章节分割线**
`# ======...======` 配合编号标题，包括嵌套在方法内部的小版本。

**B 方法内编号步骤**
`# 1. 做某事` `# 2. 做另一件事` — 把连续几行代码拆成伪步骤序号。

**C 翻译变量名的行内注释**
变量名本身已表达含义，旁边仍加 `# 是否启用xxx` `# RNN隐藏层维度` 等重复说明。

**D \[标签\] 式注释**
`# [优化]` `# [重要]` `# [修复]` 等括号标签前缀。

**F 纯装饰分隔线**
`# ---...---` 或 `# ===...===` 单独成行且不带任何文字。

**H 文件头声明注释**
`# filename.py (Part N/M)` 等由 AI 生成的分包/拆文件声明。

## 保留不动的注释

- int 枚举值说明：`# 0: NumPy, 1: CuPy`（值本身不自解释）
- 算法名称标注：`# He 初始化` `# 梯度裁剪`
- 非显而易见的决策理由：`# 推理阶段关闭 Dropout`
- 业务语义注释：`# 还原到物理坐标系 (mm)`
- 所有 docstring，无论长短

## 特殊处理

B 类注释若编号后跟着有价值的内容，去掉数字编号保留正文：

```
# 5. 时序截断划分（严禁随机打乱）  →  # 时序截断划分（严禁随机打乱）
# 1. 训练主循环                    →  删除（内容无价值）
```

## 完成后

简短报告删除了哪几类、共几处。
