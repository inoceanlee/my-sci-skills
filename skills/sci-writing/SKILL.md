# 科研与技术写作

- **核心原则：解释充分、局部独立、严格遵守本 skill ！！！**
- 默认读者接受过非常一般的高等教育，自身水平也很差，不了解当前研究的具体内容。
- 写作应让读者理解研究内容及其意义，而不只是认识专业术语、公式和数据。

## 强制 Skill 协作

使用本 Skill 时，必须实际加载并执行以下 Skills。

`anti-defensive-writing`、`anti-defensive-writing-en`、`ste-zh`、`asd-ste100``humanizer-zh``humanizer`、`no-ai-slop`、`caveman`、`sciwrite-manuscript`、`sciwrite-outreach`、`sciwrite-process`、`sciwrite-proposals`、`sciwrite-prose`、`sciwrite-publish`

- 根据正文语言选择中文或英文 Skill，不机械套用另一种语言的规范。
- `anti-defensive-writing` 在表达策略上具有最高优先级。突出真正成立的贡献，不增加自我否定、无关局限或防御性免责声明。
- 严格遵守列出的各项 skills！
- Skill 加载失败时必须明确报告，不得声称已经执行。

## 局部独立可读性

**科研文档必须同时具有整体连贯性和局部独立可读性。**

读者可能直接阅读任意章节、图表或表格，不应被迫返回前文查找理解当前内容所必需的信息。

- 各级章节均应包含理解其内容所需的关键背景、概念和条件。
- 每张图、每张表必须有相应的解释段落，且应能够独立理解。
- 专业概念即使在前文已经介绍，在新的独立阅读单元中仍须提供必要解释。
- 交叉引用用于补充细节，不得代替当前内容必需的说明。
- 为保证局部独立可读性而重复的定义、条件和解释属于必要信息，不作为冗余删除。

解释深度由实际内容决定。只补充当前部分需要的信息，避免机械重复整段背景。

## 专业内容解释

专业知识应解释到水平很差的读者能够理解其实际含义。

- **概念与术语**：解释非基础概念是什么、有什么用途，以及它与当前研究的关系。
- **指标与参数**：说明衡量对象、必要的计算口径，以及数值大小或变化代表什么。
- **公式与符号**：说明公式解决什么问题、变量及其物理意义、必要的适用条件和计算结果的含义。
- **复杂方法与理论**：按照理解所需的顺序展开，必要时先用具体情况建立直观认识，再引入抽象表达。
- 专业术语可以保留，但不能用术语代替解释。
- 基础知识无需重复科普；复杂概念也不应为了简洁而省略解释。

## 证据与结果

所有重要结论都应建立在实际证据之上，并说明其科学或技术意义。

- **数据与方法**：准确交代影响结果理解的实验条件、数据来源、处理方法和统计口径。
- **比较与评价**：明确比较对象、参考基准和评价依据，确保不同结果具有可比性。
- **结果解释**：指出重要变化、差异和规律，解释它们对当前研究问题意味着什么，而不只是复述数值。
- 区分实际测量、计算结果、理论参照与推断。
- **引用与贡献**：引用应真实、准确且支持对应论述。区分已有研究成果与当前工作的实际贡献。
- 优先围绕有充分证据支持的主要发现组织论述。
- 按照 `anti-defensive-writing` 处理不利结果和研究范围。不主动扩展与核心论述无关的局限性讨论，也不以免责声明包围已经成立的结论。

## 图表与表格

图表应使读者直接理解研究对象、数据关系和主要发现。

- 图题、表题、图注、表注及必要标识应准确说明展示内容、变量、单位和比较条件。
- 正文应分析关键结果及其意义，不逐项复述图表中的所有数值。
- 图表前后的术语解释和含义说明，必须先引用图表，不然直接说会很突兀，让人觉得很奇怪。比如：图 1 中，xx 术语是 ... 这样的。
- 图表、配文和正文结论必须一致；正文中的图表引用应准确。
- 图表的绘制、配色、尺寸和具体排版由相应绘图及文档 Skills 负责，本 Skill 只约束科学信息及其表达。
- 解释图片之前，必须用多模态的视觉能力，仔细查看图表内容！

### 图表标题

- 图题和表题使用简短、准确的名称，末尾不加句号。
- 中文标题采用自然的中文书写方式。
- 英文标题默认采用 Title Case，主要单词首字母大写，冠词、介词、连词等按英文标题大小写规则处理。
- 解释性图注和表注使用正常句子及标点，不受标题末尾标点规则限制。
- 投稿期刊、学校或指定模板另有要求时，以其规范为准。

## 句法规范

### 括号

正文中的补充说明应融入句子，不依靠括号追加完整论述。

中文示例：

- 避免：本方法采用 Hamming 窗（可以有效降低旁瓣）。
- 推荐：本方法采用 Hamming 窗以降低旁瓣。

英文示例：

- 避免：The method uses a Hamming window (which reduces sidelobes).
- 推荐：The method uses a Hamming window to reduce sidelobes.

英文缩写、必要的单位和技术符号不受此限制。

### 中英文术语

正文使用与当前语言一致的术语。
避免在中文术语后重复标注英文翻译，或在英文术语后重复标注中文翻译。
首次使用英文缩写时，给出完整名称和缩写：

- 中文：基于时间的反向传播算法（BPTT）。
- 英文：Backpropagation Through Time (BPTT).

后续统一使用已定义的名称或缩写，不反复写全术语。
独立可读不是要求反复写全术语，而是要求讲清楚这个东西是什么、有什么用、为什么要用它。

### 破折号

不使用破折号制造语气停顿，或代替正常的因果、转折关系。
英文同样避免使用 em dash（—）拼接句子。
技术术语中的连字符、数值范围符号及规范要求的标点正常保留。

### 冒号

不在正文段落中使用冒号。

### 比喻

事实性与技术性文本使用平实、直接的陈述，不用文学比喻代替具体说明。

### 模板化句式

避免用固定标签或套话组织自然段落。

中文避免：

- “机理：”“优势：”“意义：”等段内模板标签。
- “一方面……另一方面……”等缺少实际对比关系的句式。
- “需要注意的是”“值得一提的是”等无信息的铺垫。

英文避免：

- "It is worth noting that..."
- "It should be emphasized that..."
- "It is important to mention that..."
- "On the one hand... on the other hand..." 等机械对称句式。

直接表达这些句子实际承载的信息。

### 行政化与防御性口气

叙述性正文不使用命令式行政用语，也不主动替文章作负面评价。

中文避免“严格禁止”“务必”“不得”等行政口气，以及无必要的“遗憾的是”“不得不承认”。

英文避免无必要的 "Unfortunately"、"It must be admitted that"、"We acknowledge that" 等自我削弱式开头。

应说明的实际条件直接陈述，不用连续免责声明包围结果。

## 零散细节

- 同一父级标题下不得只有一个子级标题。出现这种情况时，取消该子级标题，并将其下内容及更低层级标题整体上移一级。同时对应调整文章内容和段落衔接，不能只调整标题结构，注意连贯性。
- 必须遵守中文和英文各自的表达习惯和用词习惯，避免英文生硬翻译中文，或中文生硬翻译英文。写出来的话都要像 native speaker 写的，而不是翻译软件或非母语者写的。
- 使用 Latex 或者 Typst 撰写的时候，不准硬编码图表和公式的编号，引用必须使用自动编号功能。
- 结果分析直接陈述观察、发现和结论。段落应结束于实际研究结果，不准有判断范围、参考依据及其他补充性说明。
- **正文中，边界和范围描述厌恶。** 能不写就不写，能删就删。宁删错不放过。
- **正文中，假设语句厌恶。** 只需要描述已完成的方法、结论，**没有完成、没有做的东西不要假设，不准写。**

## 全文审查

**每次完成编辑任务，必须分派一个专门的子代理，按照本 skill 的要求完成全量审查。**
要求审查标准必须极端严格，必须认真按照本 Skill 的各项要求规范，审查全文的每个部分。
审查质量和合规性优先，而非速度。

### 否定表达审查

每次写作或修订完成后，必须全文搜索以“不”“没”“未”“无”等开头的否定表达，逐条审查，**能删就删，宁可多删，不轻易保留**。
英文内容也要进行类似搜索和删除。

### 内容审查

- 从头到尾检查全部适用内容，包括摘要、正文、各级章节、公式、图表、表格、结论、引用和附录。
- 逐项执行本 Skill 的所有内容规则，检查专业解释、局部独立可读性、证据关系及结果解读。
- 必须审查 `零散细节` 这个章节中的所有条目！

### 独立阅读审查

- 分别检查每个章节、每张图表及其解释段落。
- 假设读者没有阅读其他部分，判断当前内容是否提供足够的信息，使读者理解涉及的概念、条件、结果和意义。
- 发现依赖前文才能理解的关键内容时，在当前独立阅读单元中补充必要说明。

### 外部 Skills 审查

- 必须按「强制 Skill 协作」模块，对整个文稿执行所有适用 Skills 的检查！

### 修订复检

- 修复发现的问题后，重新检查全文。
- 重点核对修改前后的事实、数据、术语、引用和结论是否一致，以及局部独立可读性是否得到保留。
- **只有全部适用规则通过检查后，才算完成正式交付。** 无法核验的内容应如实报告，不得假称验收通过。
